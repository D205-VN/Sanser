# Synthetic cross-platform H.264 fixture

`macos-h264.svc` contains 45 frames generated by the actual VideoToolbox encoder
in `native/platforms/macos/backend.mm`, with 15 red, 15 green and 15 blue frames.
It contains no captured screen, audio or account data. Dimensions are 1846×1200
to exercise display sizes that are not a multiple of 16.

Regenerate on a Mac after building native tests:

```sh
build/client-macos/cross-platform/sanser-macos-codec-test --write-windows-fixture native/test-fixtures/macos-h264.svc
```

The bounded test format is `SVC1`, three big-endian u32 values (width, height,
frame count), then access units: a big-endian u32 length, one keyframe byte,
and Annex-B H.264 payload. The Windows client test uses the production Media
Foundation decoder and conversion worker and requires the picture to advance
to the final blue frame without reference resets.

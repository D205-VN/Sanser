# Sanser Mobile 2.3.32

- **Type live from the phone keyboard:** in Remote keyboard, "Gõ trực tiếp"
  (the new default) sends each character as you type; deleting on the phone
  deletes on the computer, and a new line presses Enter. Vietnamese Telex
  letters are sent once composed. "Soạn rồi gửi" keeps the old
  compose-then-send mode.
- **Screen-sharing invitations stand out:** a new invitation shows a banner
  on any screen (with "Xem" to open it) and a count on the Chia sẻ tab.
- **iPhone sound diagnostics:** the app logs audio interruptions, route
  changes and restarts (events only, no audio) to help find a report of
  screen sound stopping after using chat. That issue is not fixed yet.

Checks: mobile Flutter tests pass; iOS simulator and device builds pass on
macOS. Not yet tried on physical phones.

Mobile version: 2.3.32, build 20340.

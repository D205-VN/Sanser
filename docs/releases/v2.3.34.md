# Sanser 2.3.34

Drag files into a session, and steadier video for phone viewers:

- **Drag and drop files:** drag a file from Finder or Explorer onto the
  remote screen window, or onto the Files panel, to send it to the other
  computer. The original file is never moved; a private copy is sent.
  One file at a time, up to 25 MB, only when file transfer is allowed.
- **Quality adapts for phones (Mac host):** when a phone viewer's network
  cannot keep up and the Mac sends too few frames, the shared picture
  steps down to 2/3 and then 1/2 size so motion stays smooth. Full size
  comes back about 20 seconds after the network recovers. Windows hosts
  keep their current behaviour.

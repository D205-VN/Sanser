# Sanser v2.1.5

- Added **Accept & trust** to incoming requests when automatic acceptance is enabled. It accepts the current request and remembers the actual requesting device for future automatic connections, without requiring a separate trip to Computers.
- Host and Settings now explain when the trusted-device list is empty. Enabling automatic acceptance alone does not trust a computer.
- Kept **Accept** as one-time approval. Trust is saved only after the server accepts the request; failed approvals do not grant future access, and storage failures are reported separately.
- Added regression tests for trusted, untrusted and disabled automatic acceptance, one-time approval, failed approval, and failed trust persistence.

Update the host, keep **Auto accept trusted devices** enabled, then choose **Accept & trust** once when your other computer requests access. Subsequent requests from that device are accepted automatically while the host is online. Existing trust choices are preserved. Both devices must remain signed in to the same account.

Includes the latency and image-clarity improvements from v2.1.4.

## Downloads

- Windows x64: `Sanser-Windows-2.1.5-x64-setup.exe` or `Sanser-Windows-2.1.5-x64-portable.exe`.
- Mac Apple silicon: `Sanser-macOS-2.1.5-arm64.dmg`. Drag Sanser to Applications.
- Signed updater bundles and SHA256SUMS.txt are included.

The macOS app is ad-hoc signed, not Apple-notarized. Windows installers do not yet have an Authenticode publisher certificate.

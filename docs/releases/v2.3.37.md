# Sanser 2.3.37

Exam fixes, an emergency unlock and stream suggestions from real measurements:

- **Exam buttons work again:** *End exam* and *Remove from exam* (and, on the
  Computers page, *Trust device* and *Remove computer*) used a confirmation
  dialog the desktop app never shows, so they did nothing. They now ask for a
  second click and show their question in place.
- **Emergency unlock:** every new exam room has an 8-character code the
  supervisor can reveal under the room code. Read to one stuck student, it
  unlocks that computer from the lock screen, also without internet; the
  supervisor sees "Used the emergency code and left the exam".
- **No stray guard:** the exam guard on Windows and macOS now stops by itself
  when Sanser is closed or killed, so apps never stay hidden.
- **Suggest settings measures first:** for a few seconds the host reports its
  CPU, memory, screen and refresh rate and tests its upload, while this
  computer tests its download. The bitrate is then based on the measured
  Mb/s instead of a guess from latency. Choose what matters most: balanced,
  smooth and stable, sharp and stable, or fastest response.
- **Frame rate shows again:** Settings → Video showed an empty frame rate
  after applying a suggestion.

Server: migration 0020 adds the emergency code to exam rooms; new advisor
probe endpoints (memory only).

Checks: server tests (76 + 19 with a database), desktop Rust tests (156),
lint, type check and unit tests (400) pass. The Windows machine-info script
and the guard's self-stop on Windows build in CI only and have not been tried
by hand; the macOS process check was tried on this Mac.

# Sanser 2.3.32

Chat where you are looking, and invitations you notice:

- **Chat in the floating panel (Mac and Windows):** the Screen sharing panel
  now has a Chat section below Voice chat, with the messages, a "Message
  everyone…" box and Send (Enter also sends). Collapsed, the panel shows
  "N new messages". Messages go through the existing session chat, so the
  main window, phones and other viewers see them too; a message that cannot
  be sent is explained in the panel.
- **Chat panel in 1:1 sessions:** the computer you connect from shows a
  compact Chat panel too, so you no longer go back to the main window to
  type. The panel takes the keyboard only while you type in its box.
- **Screen-sharing invitations notify you:** a new invitation shows a system
  notification and makes Sanser bounce in the Dock or flash in the taskbar,
  even in the background. The invitation banner offers "Enable desktop
  alerts" when notifications are off.

Checks: shared native tests (55) and the Mac floating panel test pass on
macOS; desktop unit tests (378) and Rust tests pass. The Windows panel is
built and tested by CI only. Not yet tried by hand on Windows.

# Sanser 2.3.26

- **Take back control is now a switch:** at the host computer, press
  **Ctrl+Alt+K** (Windows) or **Control+Command+K** (macOS) to turn remote
  control off, and press it again to turn it back on. Only the person at the
  host can do either; every new connection starts with control on.
- **On-screen notice at the host:** each press shows "Đã tắt điều khiển từ xa
  · Remote control off" or "Đã bật lại điều khiển từ xa · Remote control on"
  at the top of the screen for a few seconds. No notification permission is
  needed.
- **No remote pointer while control is off:** the viewer's mouse movement,
  clicks, keys, scrolling, text and controller input stop reaching the host,
  and anything the viewer was holding is released. Mac and Windows viewers
  hide their pointer over the remote screen and say so in the window title;
  phones hide the touchpad pointer and show a banner. Viewers with chat get a
  message from "Sanser" each time control turns off or back on.

Checks: shared native tests (66), mobile native tests (6), desktop Rust tests
(148) and mobile Flutter tests (161) pass on macOS. The Windows host notice
and viewer pointer are checked by the Windows CI build. Not yet tried on
physical computers or phones.

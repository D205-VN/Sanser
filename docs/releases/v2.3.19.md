# Sanser 2.3.19

This update replaces two-step verification with email sign-in codes and adds
blocked apps for hosts. The server part is already live; update the desktop
and mobile apps to see the new screens.

- **Email sign-in codes (replaces two-step verification):** signing in on a
  computer or phone that has signed in to the account before works as usual,
  from any network. A new device must enter a 6-digit code sent to the
  account's email address. Codes last 10 minutes, allow 5 attempts, and can be
  resent once a minute. A new account confirms its email with a code before it
  is created. Signing out another device from Settings makes it ask for a code
  again. Authenticator-app (TOTP) setup is removed, together with its stored
  secrets. Apps older than 2.3.19 cannot enter a code and ask you to update
  Sanser when one is needed. See [email verification](../email-verification.md).
- **Blocked apps (host):** Host page and Settings → Host → Blocked apps. Choose
  running apps or type a macOS bundle ID / Windows program name. During a
  session the remote person cannot see those apps (macOS hides their windows,
  Windows paints them black) and cannot type or click in them. The person at
  the host is not affected. Websites are not covered yet; block the browser
  instead. See [blocked apps](../blocked-apps.md) for the limits.
- **Server:** sending codes needs SMTP settings (`SMTP_HOST`, `SMTP_PORT`,
  `SMTP_SECURITY`, `SMTP_USERNAME`, `SMTP_PASSWORD`, `SMTP_FROM`). Without
  them the server asks for no code and signs in with the password only.

Checks: CI passes on macOS, Windows and Linux, including the Windows host build
and the email-code database tests (expired, wrong, replaced and exhausted
codes, trusted devices, sign-up). Desktop and mobile tests cover the code
screen. Blocked apps have policy unit tests; hiding and input blocking have not
been tried on physical computers yet, nor has email delivery to every
provider.

Mobile version: 2.3.19, build 20327. The mobile app gains the email-code step
at sign-in.

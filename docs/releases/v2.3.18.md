# Sanser 2.3.18

This update fixes support sessions from 2.3.17. Update the computers that join
support sessions with a code; the server fix is already live.

- **Support code creation (server):** "Create support code" always failed with
  "internal server error". The one-time guest password has 8 characters, but
  the server hashed it with the account password rule that requires 10. Guest
  passwords now use their own rule with the same Argon2id cost. This fix is on
  the server, so it also works with 2.3.17 apps.
- **Leaving a support session:** when the session ended (the host stopped it,
  declined, it timed out, or the guest disconnected), the guest's screen stayed
  on the session page. The server revokes the guest's access when a session
  ends, so the app could no longer read the session status. The app now treats
  that as the end of the session and returns to the sign-in screen after three
  seconds.
- **CI:** the two-step verification and support-code database tests now run on
  every push. They were written in 2.3.17 but never ran, which is how the
  password problem was missed.

Checks: the new support-code test hashes and verifies a generated guest
password; desktop tests cover returning to sign-in after an ended session and
staying while it is pending. Full desktop suite: 368 tests. The fix has not been
tried with two physical computers yet.

Mobile version: 2.3.18, build 20326. The mobile app has no changes in this
release.

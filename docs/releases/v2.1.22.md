# Sanser 2.1.22 Preview

This preview adds view-only screen sharing for up to three computers in the same
account. A host captures/encodes once and delivers through independently
authenticated SNV2/H.264 peers. Mac and Windows keep their own native backends.

On the host: go online, select **Start sharing**, choose a computer and select
**Invite**. On each invited computer: select **Join**. **Remove** disconnects one
viewer; **Stop sharing** stops the group. The host's sharing indicator remains in
the application header across pages. Viewers cannot inject input at the host.

Both desktops and the server must be updated. The server advertises
`sharing-media` after applying migrations 0006–0007. Invitations do not grant
control. A viewer is shown as watching only after its native decoder reports a
first frame for the current session generation. A group from a previous app
lifecycle is paused until the user stops it and creates a new group.

P2P reservations, signaling receivers and relay bridges now support independent
viewer sessions. Direct is preferred in Auto; fallback uses the existing UDP
relay where available, or encrypted WSS. Public UDP relay still requires actual
UDP ingress; this preview cannot supply it on a platform that only accepts HTTPS.

This is a testing release. Automated native/codec loopback, desktop and server
tests cover component behavior; real 2–3-computer Windows/Mac capture, GPU,
network and performance validation remains necessary. The previous ~200 ms route
latency is not claimed fixed. This release does not implement a privileged
Windows Secure Desktop service, audio sharing or mobile viewers.

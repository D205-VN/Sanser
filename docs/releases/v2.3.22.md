# Sanser 2.3.22

- **Blocked apps protect themselves:** whenever the host's blocked-app list is
  not empty, Sanser itself is blocked too. The person in control can no longer
  open Sanser on the host to remove the list or change other host settings.
  The limit is 64 apps chosen by the host plus Sanser.
- **Edits outside Sanser are caught:** each save of the list stores a
  fingerprint in the system keychain (Windows Credential Manager on Windows).
  If the preferences file is changed with another program, sharing does not
  start until the host checks the list in Settings → Host → Blocked apps and
  confirms it. Someone who also deletes that keychain entry is not caught.
  See [blocked apps](../blocked-apps.md).

Checks: desktop tests (374), lint, Rust tests and clippy pass. The changes have
not been tried on physical computers yet.

Mobile version: 2.3.22, build 20330. The mobile app has no changes in this
release.

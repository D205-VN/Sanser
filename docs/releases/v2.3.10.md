# Sanser 2.3.10

Two desktop layout fixes from the 2.3.9 refresh, and an API reference on the
server.

- Settings: short sections (Input, Audio and others) no longer stretch to fill
  the card, which left large gaps and an oversized select.
- Computers: the "more" menu on a computer card is no longer painted beneath
  the card below it. The hover lift that caused this was removed.
- Server: `GET /api/docs` is a self-contained, Swagger-style reference for the
  40 `/api/v2` operations with a Send request button per operation, and
  `GET /api/openapi.json` is the OpenAPI 3.0 document behind it. Both are static
  and unauthenticated. The page loads no third-party scripts and its
  Content-Security-Policy only allows requests to the same origin. A unit test
  fails when the document and the router's routes differ.

No transport, input, audio or mobile behaviour changes.

The desktop frontend passed 303 tests, the server 41 unit tests with clippy
clean, and the mobile app 147 Flutter tests. Both layout fixes were checked in a
browser preview with stubbed account data. The API page was exercised against a
static preview server, not a running Sanser server, and appears only after the
server is redeployed. Eight response bodies in the document are described only
as JSON objects.

Mobile version: 2.3.10, build 20318; the mobile app is otherwise unchanged
from 2.3.9. Android is signed locally with the existing owner-held key. The
iPhone IPA is unsigned and requires recipient signing. Mac builds remain ad-hoc
signed when no signing certificate is configured.

# Sanser 2.1.20

Add authenticated same-socket UDP echo measurements for Mac client → Windows host.
This provides a second timing path beside the control ping/pong measurements when
investigating high Direct RTT.

- Send one fixed-size authenticated probe per second on the existing media socket.
- Respond directly on the Windows receive thread, bypassing the control queue.
- Process replies on the Mac receive pump, independent of video decode/consumption.
- Show **UDP echo RTT** and **Echo host hold** in Ctrl + Option + 8 and Connection
  details; keep numeric samples in local diagnostic reports.
- Reject wrong-session, tampered, replayed, unexpected-peer and stale replies;
  rate-limit probes and retain bounded pending measurements. Older hosts display
  missing measurements rather than fabricated zero latency.

Update **both computers**, reconnect, and compare echo RTT with Control app RTT,
Socket RTT and Wire RTT estimate during 10–20 seconds of desktop/game activity.
Echo RTT still includes OS/socket scheduling and host work. It does not identify an
ISP/router fault by itself and does not automatically migrate or reconnect a route.
Other native directions do not yet implement this echo diagnostic.

Local checks: 11 native test suites (including real UDP with video consumption
stopped), 14 report tests, 145 frontend tests, Rust Clippy and frontend lint/type
checking. Real two-network latency must still be measured on the user's devices.

# Sanser 2.2.23

Update **both Windows and Mac**. This release fixes Windows privileged-helper
verification and aligns the floating Windows sharing/voice controls with the
Mac design. All packaged app/native versions and signed updater bundles are
2.2.23.

## Windows input when an elevated app opens

The affected 2.2.22 reports had remote input enabled but recorded thousands of
rejected events, zero privileged events and helper verification failure before
the readiness handshake. With an elevated foreground app, this also prevented
clicking the taskbar or switching windows through Sanser.

- Verify the connected helper through read-only Service Control Manager queries
  instead of requiring the ordinary host to open/query a SYSTEM process.
- Match the connected pipe PID to the running service, its own-process type,
  LocalSystem account and exact command in the protected installation directory.
  Caller/account/session checks and the Probe/Ready handshake remain enforced.
- Keep the real verification error and its numeric `uacCheck` stage in helper
  diagnostics, authenticated Mac status and sanitized connection reports.
  The old verifier labelled all failures Access Denied, obscuring the subcheck.

The filtered-token CI fixture marks Administrators deny-only, denies the old
SYSTEM process-query permission, then verifies a real click on its elevated
Cancel button through the authorized helper. It also rejects a user-owned fake
endpoint. Fixture-only desktop/token preparation is not part of production.
No Windows UAC policy or production desktop/process ACL is relaxed.

## Floating sharing and voice controls

- Windows now uses a subtle dark gradient, antialiased rounded surfaces/icons,
  a pill-shaped microphone button and a phone-down leave action, matching the
  Mac presentation. The white focus rectangles are removed from the
  nonactivating floating controls.
- A sharing host keeps one combined sharing/voice bar. A viewer only gets voice
  controls. The chevron expands the secondary actions; the compact mic shortcut,
  listen-only Join, explicit Unmute, Deafen and Leave behavior remain available.
- Double-buffered drawing prevents partially painted controls during hover/state
  changes. This is a presentation update, not a new audio codec or latency fix.

## Validation and remaining checks

The source baseline passed [all nine CI jobs](https://github.com/D205-VN/Sanser/actions/runs/40195991915),
including 37 Windows and 30 Mac native tests, service lifecycle/update/account
preservation, unauthorized caller rejection and the elevated Cancel click with
the old SYSTEM query denied. Six Windows panel images were rendered from a
device-free fake controller and visually checked. Versioned source checks and
installer builds run again for this release.

The elevated Cancel fixture runs on **Default**, not an actual Winlogon UAC
prompt. Test the affected game/installer and its real UAC transition on both
machines after updating. These tests do not prove that every game's input
restrictions, intermittent audio issue or WAN latency spike is resolved.
Ad-hoc Mac updates may require recording/microphone permissions to be granted
again.

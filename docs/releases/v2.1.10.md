# Sanser v2.1.10

Fixes Ultra Low Latency stuttering on variable Wi-Fi arrival times. In 2.1.9,
an intact encoded frame more than 15 ms late could force keyframe recovery and
drop most following frames. Ultra now decodes intact reference chains and keeps
only the newest decoded image for display. Actual missing-reference recovery
still waits for a keyframe once the bounded repair window expires.

- Ultra uses Auto resolution, 60 FPS and 25 Mb/s instead of 720p/120 FPS/12 Mb/s.
  Existing Ultra preferences resolve to the new defaults when reconnecting.
- Adaptive 12–50 ms gap recovery accounts for measured jitter/RTT. Contiguous
  frames are released immediately; no fixed 70 ms hold is added.
- Partial-frame loss requests repair after a 3 ms reordering grace; recovery
  timers run during UDP receive silence. Retransmit eligibility is 150 ms,
  separate from the receiver's 60 ms NACK limit.
- Windows Ultra targets a 3–5 ms software pacing budget. Actual send time still
  includes encryption, socket work and OS scheduling and may exceed this target.
- Windows desktop hosting stops drawing the extra cursor into video. The local
  client cursor remains available, avoiding the delayed second pointer.
- Windows native engines and capability probes run without a blank terminal.
- Ultra input batches are smaller, and the Mac overlay shows Host input time
  separately from Input ACK RTT.

Update both computers, select **Settings → Stream → Ultra Low Latency**, and
reconnect. **Control+Option+F8** toggles the Mac native measurements overlay.
Automated regression tests cover late intact frames, early fragment repair,
reordering, expiry, pacing bounds, application integration and Windows console
creation. Physical latency improvements still require a new run on the devices;
this release does not claim measured 5–15 ms end-to-end latency.

Server hosting is unchanged. This release does not start a server on the Mac.

Windows x64: `Sanser-Windows-2.1.10-x64-setup.exe` or portable EXE.
Apple silicon Mac: `Sanser-macOS-2.1.10-arm64.dmg`.
Updater signatures and SHA256SUMS.txt are included. macOS is ad-hoc signed,
not Apple-notarized; Windows has no Authenticode publisher certificate.

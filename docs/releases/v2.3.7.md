# Sanser 2.3.7

This update improves iPhone video recovery and Windows → Mac controls. Update
both desktop computers for automatic Mac copy/paste recognition.

- Windows Ctrl+C/Ctrl+V now sends Command+C/Command+V after the remote Mac is
  authenticated. Modifier sides, repeated presses, early release and focus reset
  are preserved. The Windows viewer system menu can disable **Mac Copy/Paste**
  for literal Control shortcuts in Terminal. This operates on the Mac clipboard;
  it does not enable automatic cross-device clipboard access.
- Preserve high-resolution wheel increments and support horizontal scrolling.
  Keep mouse capture while another button remains held, and release remote
  input if Windows loses capture. Mac injection now carries typing autorepeat
  and Caps Lock state; Unicode text remains literal.
- Correct mobile bandwidth feedback to count payload actually sent and use a
  rolling delivery window. Healthy low-rate video can recover its bitrate.
- Renew a fragmented picture's repair opportunities when new fragments arrive,
  without extending its hard expiry. Estimate paced tails from serialization
  time rather than a capped recovery deadline.
- Bound iPhone compressed-frame repair bursts, retain only the newest decoded
  image, and notify presentation immediately. Display-link ticks retry a busy
  display layer instead of adding a mandatory wait to every frame.
- Show received versus submitted display FPS and save bounded numeric decoder,
  queue and presentation diagnostics for troubleshooting.
- Recover desktop update checks/downloads through the official GitHub asset API
  when browser download URLs fail. Installer signature verification remains
  required; the Update button appears only when a newer version is found.

The Mac/native transport suite passed 45 tests. Portable copy/paste tests,
actual Mac event construction, text/shortcut permissions and VideoToolbox decode
regressions are included. OS events in input tests are collected in callbacks;
they are not proof of acceptance by every third-party app or game. A physical
Windows → Mac regression session is still needed.

Physical iPhone tests showed improvement after the repair fixes, but the user
still reported some delay/stutter before the final presentation change. This
release does not claim all stutter is eliminated or guarantee an Internet RTT.
Continuous Mac audio playback is retained.

Mobile version: 2.3.7, build 20315. Android is signed locally with the existing
owner-held key. The iPhone IPA is unsigned and requires recipient signing;
it is not an App Store/TestFlight installation. Mac builds remain ad-hoc signed
when no Developer ID certificate is configured. Existing Voice Lab deployment
and physical-device validation limitations remain unchanged.

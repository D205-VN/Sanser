# Sanser 2.3.1 — Flutter mobile preview

Adds the first Flutter/Dart mobile client source for Android and iOS, alongside
the Windows/macOS desktop application. Mobile uses shared SNV2 native transport,
H.264 native rendering, system audio, touch/HID control, secure account storage
and group-view invitations.

Mobile is an initial preview: WSS Relay only; no mobile Direct/ICE, group voice,
mobile hosting or full Unicode/IME keyboard yet. The iOS Simulator build is
unsigned and is not an iPhone installer. TestFlight/App Store distribution needs
an Apple Developer membership.

Group sessions select Relay for mobile viewers in Auto mode without changing
routing for desktop viewers. Explicit Direct-only group invitations to mobile
are rejected with a clear explanation. Desktop capture, audio and input backends
remain platform-specific; the native media data does not pass through Flutter.

Validation before publication must include Dart analysis/tests, Android APK build
and native crypto tests, iOS compilation, existing desktop/server CI and release
artifact verification. Real-device latency/audio quality are not inferred from a
successful build. The existing Direct black-screen investigation remains open.

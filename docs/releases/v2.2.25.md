# Sanser 2.2.25

Update **both Windows and Mac**. This release strengthens UDP recovery for
Mac → Windows, Windows → Windows and Windows → Mac, and adds recovery and
diagnostics for Mac headphone playback faults. App/native versions and signed
updater artifacts are all 2.2.25.

## Mac audio playback

- Inspect AudioQueue's converter error even when enqueue and `IsRunning`
  succeed. Recreate the output after a supported, nonzero converter error.
- Detect a valid device sample clock that stops advancing during playback.
  A 250 ms stall enters bounded audio-output recovery without disconnecting
  the remote desktop. Unsupported/invalid clock queries do not trigger recovery.
- Keep the last known source/sample-rate metadata on temporary query failure
  and ignore insignificant nominal-rate noise, avoiding false output restarts.
- Schedule output-error retries from the fault time so later callbacks cannot
  postpone recovery indefinitely. Keep the existing short continuity ramp.
- Add numeric converter-error and output-clock-stall counters to connection
  reports, without device names or recorded audio.

These repairs target specific failure states. The reported 3.5 mm headphone
crackle/silence still needs a physical listening test; this release does not
claim every silent endpoint can be detected from API state alone.

## UDP stability across desktop directions

- Both engines distinguish temporary UDP buffer/route errors from unusable
  sockets. Normal receive timeouts are not counted as network failures.
- Legacy Windows video preserves the successful fragment prefix and cached
  picture after a temporary send failure. Repair resumes at the missing fragment
  rather than ending transmission or skipping part of the picture.
- Legacy Mac reception consumes and classifies pending socket errors instead
  of terminating video/control demultiplexing on every temporary UDP fault.
- SNV2 reports send/receive faults explicitly. Reliable input keeps its existing
  ACK/retry deadlines; missing video uses NACK/cache repair; stale audio is not
  accumulated. Invalid sockets or partial datagram sends close cleanly.
- Add numeric transient-send/receive counters to bounded connection reports.
  Authentication, peer liveness deadlines, input safety and healthy-path
  buffering remain unchanged.

This improves recovery from specific faults; it does not guarantee zero frame
drops or a fixed Internet RTT. WSS/TCP relay behavior is outside this UDP patch.

## Validation

The [source baseline passed all nine CI jobs](https://github.com/D205-VN/Sanser/actions/runs/40646717850),
including **39 Windows native tests** and **33 Mac native tests**. These include
authenticated Auto/Ultra UDP fault injection, video NACK repair, reliable
key-down/up retry, terminal socket shutdown, legacy fragment-prefix repair,
synthetic output clock/converter recovery and **27 connection-report tests**.
Versioned source checks and installer builds run again for this release.

Real Windows/Mac GPUs, long listening, 3.5 mm jack changes, group voice and
three-direction LAN/WAN soak tests still require validation. Synthetic tests
verify recovery behavior and do not prove that every previously reported lag,
freeze, audio or game-input issue is fixed.

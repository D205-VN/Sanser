# Sanser 2.3.16

This update tidies the host page and ends shared screens cleanly. Update the
host and every viewer.

- Share with multiple computers: when the host stops sharing, removes a viewer
  or goes offline, each viewer now closes its shared view and returns to the
  main screen. Before, the viewer treated the vanished host as a broken route
  and kept retrying the connection. The viewer checks the server session first,
  so no reconnection attempt or error is shown.
- Host page (Windows and Mac): errors are no longer shown in red on the host
  page, the sharing panel or host group voice. They are recorded in
  Settings → Diagnostics instead. The yellow "server update required" warning
  is still shown.
- iOS build: the Rust part of the mobile library is now built for iOS 15, the
  same minimum as the app. A library built with a newer SDK could otherwise
  require the newest iOS on older iPhones.

Checks: a new desktop test closes a shared view when the server reports the
sharing session ended, with and without a running native viewer, and fails on
2.3.15 code. Host page tests now check that errors go to Diagnostics instead of
the page. Full desktop suite: 305 tests. No physical multi-computer session has
validated this release yet.

Mobile version: 2.3.16, build 20324.

# Sanser 2.3.27

- **Forgot password:** the sign-in screen on Mac, Windows, iPhone and Android
  has **Forgot password? / Quên mật khẩu?**. Enter the account email and
  Sanser emails a 6-digit code. Enter the code with a new password to set it.
  The code lasts 10 minutes; a new one can be asked for once a minute.
- **Everyone else is signed out:** setting a new password signs out every
  computer and phone of the account and signs in the one that asked, which
  is remembered so it needs no second code.
- **No account guessing:** the answer is the same whether or not an address
  has an account; unknown addresses get no email and no code works for them.
  Reset codes never complete a sign-in, and sign-in codes never reset a
  password. Reset emails count toward the same 8-per-hour limit per address.
- **Server:** new endpoints `POST /api/v2/auth/password/forgot` and
  `POST /api/v2/auth/password/reset` (see
  [email sign-in codes](../email-verification.md)); migration
  `0018_password_reset.sql` adds the `reset` purpose to email challenges.
  The server needs email (Resend or SMTP) configured; otherwise the request
  answers 503.

Checks: server unit tests (59), desktop tests (377) and mobile Flutter tests
(162) pass on macOS. The database-backed reset test runs in the CI
server-integration job. Not yet tried against the production server.

# Sanser 2.2.18

Update **both Windows and macOS computers**. This release packages the audio,
upside-down sharing and voice-control fixes developed after 2.2.17. Installers,
native engines and signed updater bundles carry the same version.

## Fixes

- **Mac controlling Windows: missing sound.** The legacy Mac multiplexed audio
  listener no longer rejects queued packets because they lack a second
  `recvfrom` address. The main socket still validates the sender; dedicated audio
  sockets retain their peer lock, authentication and replay checks.
- **Windows group sharing: upside-down image on Mac.** Metal presentation uses
  an explicit Core Image destination orientation instead of an extra canvas
  flip. Tests now cover a real drawable as well as an offscreen texture and
  VideoToolbox-decoded pixels.
- **Join voice reverting to Join.** The UI waits for native confirmation and
  ignores stale status reads. Mute/Leave retain the known capture indicator until
  native confirmation instead of prematurely claiming the microphone is off.

## Floating voice controls

During **Share with multiple computers**, both the host and viewers have a native
floating **Sanser · Voice** button on Windows and macOS. Click to expand:

- **Join voice** listens only. **Unmute mic** explicitly enables the microphone.
- **Mute mic**, **Deafen/Hear voice** and **Leave voice** are available without
  returning to the main Sanser window.
- The compact button shows mic state. Collapsing it or changing pages preserves
  the call; disconnecting or ending sharing closes capture and the panel.

Microphones remain off by default and consent is not restored on a new engine
or reconnection. Older engines without floating controls still leave voice on
page navigation. Use headphones; acoustic echo cancellation is not included.

## Validation and remaining checks

The implementation CI passed all nine jobs. Local checks passed 248 frontend,
89 desktop Rust and 28 macOS native tests; Windows CI passed its 34 native tests,
including the floating controls. An existing viewer-congestion timing test
needed a rerun. The prior audio and rendering implementations were each restored
temporarily to verify that the new regression tests fail before the fix.

Synthetic tests do not open microphones, play hardware sound or capture another
application. Actual two-machine system audio, microphone permissions, headsets,
full-screen use and long group calls still require device testing. This release
does not claim all crackling, group freezes or roughly 200 ms Internet paths are
universally resolved, and does not promise 5–15 ms latency.

Downloads include Windows x64 setup/portable, Apple Silicon Mac DMG/ZIP, signed
updater bundles, `updater-latest.json` and SHA-256 checksums. If built without Apple
Developer ID, macOS recording/microphone permissions may need to be regranted
after updating.

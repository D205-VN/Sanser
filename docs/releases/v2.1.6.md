# Sanser v2.1.6

- Computers now show the machine name and a short identity code, making similarly named Macs and PCs easier to distinguish. Custom names are preserved after signing in again.
- Desktop identities are saved in the native application configuration per account. Signing out, signing back in, updating, or switching between development and installed builds reuses the saved identity. Existing role IDs are imported when available, preserving trusted-device choices.
- Host and Client registrations with the same saved computer identity appear as one card. Connections use the host identity; trust uses the requesting client identity.
- The server reuses the existing registration for each account, computer, and role, including concurrent registrations. Pin, rename, and remove actions apply to both roles on a grouped card.
- Older offline registrations with generic names are tucked under **Older offline registrations**. They remain available to inspect, rename, or remove. Old entries without reliable identity metadata are not automatically merged or deleted.

Update both computers and sign in again to register their identities. Keep application data when reinstalling: deleting that data creates a new installation identity. The server must also be updated to support grouping; older servers remain compatible with stable role IDs.

Includes the trusted-device approval improvements from v2.1.5 and latency/image-clarity improvements from v2.1.4.

## Downloads

- Windows x64: `Sanser-Windows-2.1.6-x64-setup.exe` or `Sanser-Windows-2.1.6-x64-portable.exe`.
- Mac Apple silicon: `Sanser-macOS-2.1.6-arm64.dmg`. Drag Sanser to Applications.
- Signed updater bundles and SHA256SUMS.txt are included.

The macOS app is ad-hoc signed, not Apple-notarized. Windows installers do not yet have an Authenticode publisher certificate.

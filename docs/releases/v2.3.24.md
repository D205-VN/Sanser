# Sanser 2.3.24

- **Full screen on Windows:** when a Windows computer connects to another
  computer, the remote screen now opens in true full screen: no frame, no
  title bar, and the taskbar is covered. Press **Ctrl+Alt+Enter** (or use
  *Full screen* in the window menu, Alt+Space) to switch between full screen
  and a normal window; the window returns to its previous size and place.
  The shortcut is never sent to the remote computer and releases held keys.

Checks: shared native tests (66) pass on macOS; the Windows viewer change and
its window test are checked by the Windows CI build. Not yet tried on a
physical Windows computer.

Mobile version: 2.3.24, build 20332. The mobile app has no changes in this
release.

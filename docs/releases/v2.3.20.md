# Sanser 2.3.20

A small fix for Windows on top of [2.3.19](v2.3.19.md).

- **Readable drop-down lists on Windows:** an open drop-down list, such as
  **Choose from running apps** under Blocked apps, showed light text on a white
  background, so most entries could not be read. Every drop-down in the app
  now opens with a dark background and light text; the current entry is
  highlighted and unavailable entries are dimmed. macOS was not affected.

Checks: full desktop suite, 372 tests. The new colors have not been checked on
a physical Windows computer yet.

Mobile version: 2.3.20, build 20328. The mobile app has no changes in this
release.

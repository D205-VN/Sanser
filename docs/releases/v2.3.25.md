# Sanser 2.3.25

- **Smoother video on phones over Wi-Fi:** phones on Wi-Fi pause for about
  100 ms every few seconds to save power. The computer sharing its screen
  took each pause for congestion and kept video at its lowest quality
  (1 Mbps) for the whole session, so the picture arrived in bursts. A single
  brief pause now only holds quality back for under a second; real,
  lasting congestion still lowers it as before.
- **Clearer voice from phones:** the iPhone microphone now sends sound every
  10 ms instead of in 100 ms bursts, and it keeps working when the phone's
  audio route or volume changes.
- **Steadier sound through Wi-Fi pauses:** voice and screen sound buffer up
  to 140 ms and 120 ms when the network needs it (previously 100 ms and
  60 ms). Packets that arrive together after a pause are played, not
  discarded. The buffer shrinks again when the connection is calm.

Checks: shared native tests (66) pass on macOS, including new tests for
isolated Wi-Fi delay spikes and ~100 ms delivery stalls. Measured on an
iPhone XS Max over Wi-Fi: the Mac decoded 1129 voice blocks in 25 s with
the new microphone path (302 before). The video and voice buffer changes on
the computer are covered by tests but not yet measured on a phone.

Mobile version: 2.3.25, build 20333.

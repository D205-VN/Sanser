# Sanser 2.3.21

- **Take back control from the host:** the person at the host computer can
  press **Ctrl+Alt+K** (Windows) or **Control+Command+K** (macOS) during a
  session. The viewer keeps seeing the screen, but their mouse, keyboard,
  scrolling, typing and game controller no longer reach the host until the
  session ends. Keys or buttons the viewer was holding are released once so
  nothing stays pressed. It cannot be undone during the session; the next
  connection has control again. Viewers with chat get a message from Sanser.
  The hotkey hint is in Settings → Host and on the Host page. While a session
  with remote input is open, other apps on the host do not receive these keys.
  See [stop remote control](../stop-remote-control.md).
- **Email codes (server):** the server can send sign-in codes through Resend's
  HTTPS API (`RESEND_API_KEY`, `EMAIL_FROM`), and gives up on a mail server
  after 8 seconds so the app shows an error instead of a timeout. SMTP through
  Brevo on port 2525 is documented for hosts that block mail ports. See
  [email verification](../email-verification.md).

Checks: the macOS engine builds and passes its native tests; the Windows
engines build and the new cutoff policy test passes there. Desktop tests: 373.
The hotkey has not been tried on physical computers yet. One existing sharing
test (`sanser-broadcast-policy-test`) fails intermittently in Windows CI; it is
unrelated to these changes and is being fixed separately.

Mobile version: 2.3.21, build 20329. The mobile app has no changes in this
release.

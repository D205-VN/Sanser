# Sanser 2.3.35

Easier first steps and a computer that stays ready:

- **Start Sanser when you sign in:** Settings → Host has a new switch that
  opens Sanser in the background after the computer starts (a per-user
  LaunchAgent on macOS, the per-user Run entry on Windows; no administrator
  rights). On Windows it starts in the tray. Combine it with *Bring host
  online automatically* to keep the computer reachable.
- **Get started guide:** the Computers page shows three steps that tick
  themselves off: install Sanser on a second device, turn on Host, make the
  first connection. You can hide it, and it disappears once you are done.
- **Network check:** Diagnostics can measure the round trip to the Sanser
  server, whether direct UDP leaves this network, whether the router opens
  ports itself, and IPv6. The Computers page runs it quietly (at most every
  10 minutes, never during a session) and warns only when connections will
  have to use the slower relay.

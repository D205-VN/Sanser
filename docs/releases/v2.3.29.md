# Sanser 2.3.29

- **Phone pointer lines up with the click:** in touchpad mode on iPhone and
  Android, the pointer used to be drawn about 6 px to the right of and 3 px
  above the point the host actually clicked, so it looked offset from the
  host's own pointer in the video. It is now a classic arrow whose tip is
  exactly the click point, white with a dark outline so it shows on light
  and dark screens.

Checks: mobile Flutter tests (163) pass, including a new test that the
pointer tip matches the click position. Not yet tried on physical phones.

Mobile version: 2.3.29, build 20337.

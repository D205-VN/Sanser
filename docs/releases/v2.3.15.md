# Sanser 2.3.15

This update targets group-voice clarity and stuck keys when a Mac controls
another computer. Update every computer in the call.

- Group voice, after studying open-source voice chat clients (no code copied):
  - Each voice datagram also carries the previous 20 ms of speech (`SVO2`), so
    a single lost packet plays real speech instead of a concealment guess.
    Peers opt in with an `SVR1` keepalive; older engines keep receiving
    `SVO1`. Voice uses about 128 kbps per talker instead of 64 kbps.
  - Each speaker's playout reserve adapts from 20 to 100 ms: a late packet
    adds 20 ms without skipping speech, ten calm seconds give 20 ms back
    during a pause. Duplicates no longer count as late.
  - The microphone runs through RNNoise 0.2 (Xiph, BSD) noise suppression,
    an automatic gate driven by RNNoise's voice-activity estimate (opens on
    speech, holds 300 ms, fades to -30 dB) and a -1 dBFS peak limiter. This
    adds 10 ms. `SANSER_VOICE_RAW=1` sends the echo-cancelled mic unprocessed.
  - Microphone blocks are no longer discarded because of normal device input
    latency. A 2.3.14 Mac sharing log showed ~10 blocks per second dropped,
    each resetting the encoder and echo canceller: heard as crackle.
- Stuck keys: AppKit never delivers a key release while Command is held, so a
  Mac viewer sent Cmd+Z, Cmd+S, Cmd+arrow and similar key presses to the host
  without their releases. Both the Mac-to-Windows client and the Mac-to-Mac
  view now forward those releases.

A microphone that clips at its input (input volume set too high) cannot be
repaired afterwards; lower it in the system sound settings.

Checks: new tests for SVO2 wire format and loss recovery, adaptive voice
reserve under periodic 45 ms jitter, microphone capture staleness, and the
voice cleaner (noise removed, speech within 2 dB, no output above -1 dBFS),
plus the full Mac (48) and mobile native (6) suites. RNNoise and the Windows
voice changes are first compiled for Windows by release CI. The Command-key
release fix has no automated test that can hold a physical Command key, and
no physical session has validated this release yet.

Mobile version: 2.3.15, build 20323. Phones do not use group voice.

# Sanser v2.1.3

- Fixed Windows hardware encoder processing: asynchronous Media Foundation encoders now wait for METransformNeedInput and METransformHaveOutput before submitting frames or requesting output. This addresses premature ProcessOutput calls returning HRESULT 0x8000FFFF.
- Retain the encoder event generator, handle asynchronous errors, drain queued output with a bounded timeout, and shut down hardware workers before releasing Media Foundation.
- Fall back to software encoding if hardware initialization or frame encoding fails, preserving the network/control session. Software encoding can use more CPU and deliver a lower frame rate.
- Added Windows tests for asynchronous event scheduling and actual software H.264 encoding on a machine without a GPU.

Update both computers, restart Sanser, and reconnect. NVIDIA/Intel GPU driver behavior on physical devices still needs verification; CI does not exercise those hardware encoders.

## Downloads

- Windows x64: `Sanser-Windows-2.1.3-x64-setup.exe` or `Sanser-Windows-2.1.3-x64-portable.exe`.
- Mac Apple silicon: `Sanser-macOS-2.1.3-arm64.dmg`. Drag Sanser to Applications.
- Signed updater bundles and SHA256SUMS.txt are included.

The macOS app is ad-hoc signed, not Apple-notarized. If first launch is blocked, verify the download and use System Settings → Privacy & Security → Open Anyway. Windows installers do not yet have an Authenticode publisher certificate.

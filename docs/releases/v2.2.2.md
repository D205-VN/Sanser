# Sanser 2.2.2

Fixes missing **Join** buttons for screen-sharing invitations in 2.2.1. Pending
invitations do not have a media session ID yet; the old UI compared that absent
ID to the absent local connection and incorrectly hid every new invitation.
The UI now excludes only an already-open media session, while retaining exact
viewer-device matching and explicit Join/Decline consent.

Invitation polling recovers after a transient startup/server failure. Concurrent
initialization shares one request, Computers **Refresh** also checks invitations,
and a failed load is visible with **Retry invitations**.

The host picker offers current online viewer registrations and distinguishes
computers by their installation ID, preserving separate machines with identical
names. An old invitation targeting an offline registration identifies that state
and can be removed/reissued. The server rejects new invitations to offline
viewers and stores the registering desktop's actual version, so older desktops
cannot inherit the server's newer feature eligibility.

Update the Windows/Mac viewer to 2.2.2 and open **Computers**. Join appears in the
invitation at the top of the workspace. If the old invitation targets an offline
registration, remove it on the host and invite the online computer again.
Update the server for the offline-invitation and accurate-version checks;
if `SANSER_VERSION` is explicitly set there, use `2.2.2` or omit the override.

This patch keeps the existing SNV2/H.264 sharing pipeline and protocol v2.
Physical multi-machine/GPU/WAN testing is still required; the previously reported
approximately 200 ms path latency is not claimed fixed by this invitation patch.

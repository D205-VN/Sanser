# Sanser 2.1.11

On Windows, closing the main window now keeps Sanser running in the system tray.
An online Host can continue accepting connection requests and an active remote
session can continue while the main window is hidden.

- Click the tray icon or choose **Open Sanser** to restore the window.
- Right-click the icon and choose **Quit Sanser** to exit completely. Native
  engines are stopped on application exit, including updater restarts.
- Host settings explain the close-to-tray behavior. Existing Host online,
  trusted-device and approval settings still apply.
- Windows WebView2 timer throttling is disabled for the main window so background
  heartbeat and request polling can continue.

This does not install a Windows service or automatic startup task. The computer
must remain awake and the user must remain signed in. Closing the native viewer
still closes that viewer normally. macOS window behavior is unchanged.

This release does not change Direct/Relay negotiation or move the server to the
Mac. Real Windows tray interaction and long-duration hidden-window hosting need
validation on installed devices; compilation and automated tests do not measure
those behaviors. See [Windows background operation](../windows-background.md)
for the acceptance checks.

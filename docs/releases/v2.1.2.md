# Sanser v2.1.2

- Fixed a Windows relay startup race: packets arriving before the native engine binds its UDP port could close the relay and make the other computer report that its peer went offline.
- Retry only UDP port-unreachable/reset errors during the initial 25-second startup window. Other socket errors still fail and now include the operating-system error details.
- Report a clear local native startup timeout if the engine sends no UDP packets within that window.
- Added Windows CI coverage for encrypted relay traffic before and after a delayed native engine startup.

Update both computers, disconnect the failed session, then reconnect. This fix addresses the tested startup race; it does not establish that every reported relay failure has the same cause.

## Downloads

- Windows x64: `Sanser-Windows-2.1.2-x64-setup.exe` or `Sanser-Windows-2.1.2-x64-portable.exe`.
- Mac Apple silicon: `Sanser-macOS-2.1.2-arm64.dmg`. Drag Sanser to Applications.
- Signed updater bundles and SHA256SUMS.txt are included.

The macOS app is ad-hoc signed, not Apple-notarized. If first launch is blocked, verify the download and use System Settings → Privacy & Security → Open Anyway. Windows installers do not yet have an Authenticode publisher certificate.

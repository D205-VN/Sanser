# Sanser 2.3.3 — Mobile controls and streaming stability

Mobile adds direct touch and a relative touchpad, right-click, two-finger vertical
scrolling, 1–3× zoom/pan, reset-to-fit, arrow/function keys and shortcuts. Optional
game controls map to keyboard keys (WASD, Shift, Space, E and Escape); they are not
a native Xbox/XInput controller. View-only sessions remain unable to send input.
Held buttons and keys are released on cancellation, backgrounding and disconnect;
stale sessions cannot send input into a later connection.

Settings can copy the last 120 numeric receiver diagnostic samples, including
completed video frames, missing fragments, repair requests and Opus/PLC counters.
The report excludes credentials, endpoints, media and typed input. Received-frame
rate is not a measurement of display FPS or end-to-end latency.

Streaming fixes target the stutter seen when mobile media starts:

- Negotiated sender bitrate updates receiver repair timing. Fragments still being
  serialized by the original sender are not immediately mistaken for packet loss.
- Repeated RTT spikes trigger bounded bitrate reductions even when healthy samples
  occur between them. Recovery is delayed to avoid immediate bitrate oscillation;
  network adaptation preserves FPS.
- Single-viewer mobile hosts skip superseded raw capture/encode work when sending
  falls behind, preserving encoded reference frames. Mac retains the newest raw
  image and refreshes the final idle image. Slow group viewers do not globally
  throttle capture through this policy.
- Mobile keyframes have a bounded 1.5-second send expiry, with matching receiver
  repair/cache limits. Complete frames are delivered immediately; this expiry is
  not a fixed presentation buffer. Desktop and interframe bounds remain intact.
- Apple media workers request explicit interactive QoS rather than inheriting
  background timer behavior. Desktop Windows capture/codec backends are retained.

Validation: 36 Flutter tests, clean analysis, 31 Mac native desktop tests and five
mobile native tests; Windows host, iPhone Release/AOT and Simulator builds pass CI.
UDP tests cover lossless paced keyframes, real fragment loss, bounded sender
stalls, expired-frame recovery and producer overload without encoded queue drops.
These checks do not prove that all real-device jitter or audio distortion is fixed;
comparisons on the user's phone and network are still needed.

Update Windows/macOS hosts as well as the mobile viewer to use the negotiated
policy. Android ARM64 preview APKs are signed locally using the existing Sanser
certificate; the signing key remains on the Mac. The iOS 15+ ARM64 Release/AOT IPA
is unsigned and requires recipient signing before installation. It is not a
universal tap-to-install or TestFlight build; see `README-iPhone-install.md`.

Mobile remains a preview: no microphone/group voice, mobile hosting, UDP Relay,
native IPv6 media or full Unicode/IME input. NAT and network isolation can require
WSS Relay. No fixed Internet RTT or interruption-free streaming is guaranteed.

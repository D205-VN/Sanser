# Sanser 2.2.19

Update **both Windows and macOS computers**. This release packages the compact
floating sharing/voice controls and the audio, administrator-input and decoder
startup repairs developed after 2.2.18. App, native engines and signed updater
bundles use the same version.

## Compact floating controls

- **Sharing host:** one dark, rounded bar combines the screen-sharing indicator,
  microphone shortcut, expand arrow and red Stop sharing button. The old separate
  sharing notice and voice window are replaced by this single panel.
- **Viewer:** only the floating Group voice bar is shown, without sharing/Stop
  controls. Expand it for icon buttons to Join, mute/unmute, deafen and leave.
- Icons have tooltips and accessible names. The bar can be dragged without taking
  keyboard focus; microphone state stays visible while collapsed.
- Join listens only. Unmute explicitly enables capture; collapsing preserves the
  call. Stop sharing also leaves voice. Hosts without voice support retain their
  screen-sharing indicator and Stop button.

## Audio and connection startup

- The legacy Mac audio player restarts stopped output and recovers stalled device
  callbacks instead of assuming continued decoding proves audible playback. Old
  PCM is dropped on recovery; the output queue remains bounded.
- Group voice drains PCM according to elapsed audio time, avoiding undersupply
  when the worker wakes late. SpeexDSP acoustic echo cancellation processes the
  microphone using playback references before Opus encoding. System music does
  not pass through the speech processor; license notices are included.
- Decoder warmup waits for an actual decoded picture, rather than a successful
  compressed-input call. This preserves startup reference frames on decoders
  that accept input before producing output.

## Windows administrator input

The normal setup/update installs or refreshes the protected administrator helper
after Windows administrator approval, preserving a previous explicit Disable.
Protected copies are verified instead of silently using a stale helper. The
privileged input worker obtains the interactive desktop rights needed for an
administrator installer's controls; failures remain visible rather than being
reported as successful ordinary input. Portable installations retain the manual
Enable UAC support action. Windows UAC itself is not disabled or bypassed.

## Validation and remaining checks

The earlier audio/UAC/decoder source changes passed all nine CI jobs, including
29 Mac and 35 Windows native tests and the elevated Cancel fixture. The compact
panel has device-free tests for host/viewer roles, listen-only Join, explicit
Unmute, compact Mute, collapse, Deafen, Leave and Stop sharing. Final release
validation also builds the Windows and Mac installers and signed updater bundles.

Synthetic tests do not establish the acoustic quality of a particular speaker,
microphone or Bluetooth device. Test both computers after updating, including
system music plus group voice, permission denial, full-screen controls, long
sharing calls and third-party administrator installers. This release does not
claim every audio artifact, sharing freeze or roughly 200 ms Internet route is
resolved, and does not promise 5–15 ms WAN latency.

Downloads include Windows x64 setup/portable, Apple Silicon Mac DMG/ZIP, signed
updater bundles, `updater-latest.json` and SHA-256 checksums. Ad-hoc Mac builds may
need screen-recording/microphone permissions regranted after the update.

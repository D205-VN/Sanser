# Sanser v2.1.0

- Refreshed desktop interface with an Update button in the upper-right corner.
- Optional remembered sign-in, with sign-out after seven days without activity.
- Native Mac and Windows hosting/client roles and improved connection lifecycle.
- Fixed AES encryption of empty Windows control packets that prevented handshakes.
- Update installation waits until remote sessions finish.

## Downloads

- Windows x64: `Sanser-Windows-2.1.0-x64-setup.exe` (installer) or `Sanser-Windows-2.1.0-x64-portable.exe`.
- Mac with Apple silicon: `Sanser-macOS-2.1.0-arm64.dmg`. Open the DMG and drag Sanser to Applications.
- SHA256SUMS.txt contains checksums. Signed updater bundles are used by the in-app Update button.

The macOS build is ad-hoc signed, not Apple-notarized. macOS may block its first launch; after verifying the download, use System Settings → Privacy & Security → Open Anyway. Windows installers do not yet have an Authenticode publisher certificate.

Both devices need matching desktop builds, and the server must support the new device roles. Automated Windows/Mac tests pass; testing real devices across different networks remains separate.

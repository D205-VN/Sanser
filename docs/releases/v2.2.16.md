# Sanser 2.2.16

This release packages the four media/network improvements developed after 2.2.15.
Update **both desktops** to use the new negotiated features.

- **Opus + PLC:** statically bundled 96 kbps stereo low-delay Opus, bounded reorder
  and packet-loss concealment, independent audio sequences, and PCM fallback for
  older peers. No external codec installation or microphone forwarding.
- **Measured standby Direct paths:** keep probing authenticated alternative
  candidates and switch only to a verified path that passes the health/improvement
  policy. Retain the chosen media socket, permissions and replay checks. A better
  route must actually exist; this does not promise 10 ms Internet latency.
- **Adaptive video FEC:** shared Direct/UDP Relay XOR protection, negotiated at
  both ends. Recover one missing datagram per 8–16-packet block, cap parity wire
  spending at 8–15%, and pause on congestion. Originals are forwarded immediately;
  NACK/IDR still handles larger loss. WSS/TCP does not use FEC.
- **Group sound and independent mute:** one system capture and Opus encode feeds
  up to three separately authenticated view-only viewers. Windows SNV2 loopback
  capture and Mac SNV2 playback complete the platform paths. Each viewer can mute
  or unmute in Active session without restarting video or affecting other viewers.
  Host audio must be enabled before starting sharing. macOS system capture requires
  macOS 13+ and Screen & System Audio Recording permission.

Windows/macOS native, Rust, frontend and server CI includes loss/recovery fixtures,
three-viewer mixed-codec audio, one-encode verification, mute/unmute, video
continuity, isolated viewer close and PCM conversion. These are automated synthetic
tests, not physical listening or measured two-machine P50/P95 latency acceptance.

Still open: real-device Share freeze and audio validation in both directions,
roughly 200 ms UDP paths/2 s user-observed lag, public UDP Relay deployment
(requires public UDP ingress), VPN MTUs, permission/device changes and full UAC
Secure Desktop support. Group size remains three. No claim is made that all
reported lag, disconnects or crackle is fixed by this release.

Installers: Windows x64 setup/portable, macOS Apple Silicon DMG/ZIP; signed updater
bundles and `updater-latest.json`. A Mac build without Developer ID remains ad-hoc:
macOS may require Screen Recording permission to be granted again after updating.

[group audio](../group-audio.md).

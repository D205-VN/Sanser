# Sanser 2.1.21

This release fixes an Auto fragment-repair timing bug, improves recovery after
Windows desktop/capture transitions, and identifies virtual/overlay candidates
more clearly.

- Auto now requests missing video fragments before the host retransmit cache
  expires, including on an idle desktop. Startup requests a fresh keyframe if
  video arrives without a decoded image, with bounded retries.
- New media generations clear partial assemblies and obsolete repair requests.
  Connection reports include missing fragments and NACK recovery counters.
- Windows retains a healthy capture device across desktop switches and updates
  the encoder when a new device is needed. Capture pauses preserve the session;
  Mac displays a desktop-unavailable notice, and recovery requests a keyframe.
- feth and other virtual adapter names are classified before Ethernet. VPN and
  ZeroTier paths remain eligible for measured selection. Diagnostics shows the
  advertised local interface where it can be matched reliably.

Install matching builds on both computers for capture status telemetry. Native
tests cover fragment loss, reordering, startup retries and generation changes;
real UAC/lock/unlock and WAN tests on two computers remain necessary. This does
not enable viewing or controlling Secure Desktop, deploy an Internet UDP relay,
or implement live route migration. No 5–15 ms latency guarantee is made.

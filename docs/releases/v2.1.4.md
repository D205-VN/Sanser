# Sanser v2.1.4

- Fixed the legacy Windows-to-Mac stream inheriting a 250 ms screenshot delay after every frame. Streaming now defaults to FPS pacing, enabling the existing adaptive frame-rate and startup bitrate controls; explicit capture intervals are still supported.
- Corrected the Windows encoder quality/speed setting from 100 (slowest, highest complexity) to 33 (speed-prioritized), while retaining low-latency mode and no B-frames.
- Auto now targets 25 Mb/s and lets the Windows-to-Mac capture preserve a 1920 × 1200 desktop instead of reducing it to 1728 × 1080. Smaller sources are not upscaled; explicit resolution presets and SNV2 capture dimensions remain unchanged.
- Added regression checks for FPS-based launch arguments, Auto capture dimensions, and encoder output before end-of-stream drain.

Update both computers, restart Sanser, select **Settings → Stream → Auto** on the controlling computer, and reconnect. Physical-device latency and visual quality still require verification; automated tests do not measure the delay on your Wi-Fi or GPU.

## Downloads

- Windows x64: `Sanser-Windows-2.1.4-x64-setup.exe` or `Sanser-Windows-2.1.4-x64-portable.exe`.
- Mac Apple silicon: `Sanser-macOS-2.1.4-arm64.dmg`. Drag Sanser to Applications.
- Signed updater bundles and SHA256SUMS.txt are included.

The macOS app is ad-hoc signed, not Apple-notarized. Windows installers do not yet have an Authenticode publisher certificate.

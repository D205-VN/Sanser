# Sanser 2.3.17

This update adds ten features and a Vietnamese/English language switch. Update
the server first, then every computer. Without the 2.3.17 server, sign-in and
connections keep working, but two-step verification, support codes, Wake-on-LAN,
connection history and recording consent are unavailable. The server applies
its new database migrations (0013, 0014, 0016) automatically when it starts.

- **Language:** the desktop app is now in Vietnamese by default. The VI | EN
  switch is in the title bar, on the sign-in screen and in Settings → Account.
- **Choose a display** (SNV2 sessions): when the host has several monitors, the
  viewer can switch between them on Active session. Legacy Mac → Windows
  sessions and group sharing stay on one display.
  See [multi-monitor and privacy screen](../multi-monitor-and-privacy-screen.md).
- **Privacy screen** (host only, off by default): while a computer controls
  yours, your own monitor shows a black screen that is not sent in the video.
  Only the host can turn it on; a viewer cannot. Blocking local keyboard and
  mouse is optional and needs the Windows UAC helper; it is unavailable on Mac.
- **Two-step verification:** Settings → Security turns on 6-digit codes from an
  authenticator app, with 10 recovery codes. See [two-step verification](../two-factor.md).
- **Support sessions without an account:** the host creates a one-time code and
  password; the other person chooses "Connect with a code" on the sign-in
  screen. The host must still accept, and guests start view-only.
  See [guest access](../guest-access.md).
- **Chat and pen:** text chat and temporary pen strokes during a session and in
  group sharing. Content travels on the encrypted session link and is not stored
  on the server. See [chat and annotation](../session-chat-annotation.md).
- **Wake-on-LAN** (opt-in): wake a sleeping computer from another computer on
  the same local network. See [Wake-on-LAN and history](../wake-on-lan.md).
- **Connection history:** who connected to which computer, when, and for how
  long, kept for 90 days.
- **Recording:** a viewer can record a 1:1 session or a shared screen to an MP4
  file in Downloads/Sanser/Recordings. The host is always told, and can turn
  off recording in Host settings. HEVC sessions are not recorded.
  See [recording and bug reports](../recording-and-bug-reports.md).
- **Report a problem:** Settings → Diagnostics saves a zip of diagnostics with
  tokens, emails and IP addresses removed, and can open a prefilled GitHub
  issue. Nothing is sent automatically.

Checks before tagging: 365 desktop tests, 387 Rust tests (25 ignored), clippy,
lint, and 64 macOS native tests pass on a Mac. The Windows engine changes are
built and tested by CI. Server tests that need a PostgreSQL database run in CI
only. No feature in this release has been tried on physical Windows and Mac
computers yet; the linked documents list what still needs checking.

Mobile version: 2.3.17, build 20325. The mobile app has no new features in this
release.

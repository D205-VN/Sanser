# Sanser 2.3.23

Phone release: voice, chat, background sessions and picture in picture.

- **Group voice on phones:** a phone watching a shared screen can join the
  group voice room, listen and turn its microphone on (permission is asked the
  first time). iOS uses its voice processing for echo cancellation; Android
  uses the voice-call recorder with the platform echo canceller. Headphones
  avoid echo from loud screen sound on Android.
- **Chat in the session:** a **Chat** button on the phone talks to the desktop
  in-session chat (text only, 1 KB per message, not saved). In sharing
  sessions the host relays it to the other viewers.
- **Sessions survive leaving the app:** Settings → *Giữ kết nối khi thoát ra*
  (off, 5, 15 or 60 minutes; 15 by default). Sound, voice and chat continue;
  an updated computer stops sending video until the picture is visible again.
  If the session dropped while you were away, returning reconnects it instead
  of going back to the list. Android shows an ongoing notification meanwhile.
- **Picture in picture:** leaving the app keeps the computer screen in a
  floating window (on by default, can be turned off in Settings).
- **Notifications:** local notifications for chat messages and dropped
  sessions while Sanser is in the background. No push server is used.
- **Computers:** desktop engines understand the phone's "picture hidden"
  signal (`SVH1`) and pause video for that viewer only. Older computers keep
  sending video and everything else still works.

Checks: native mobile tests (6), desktop native tests (66), Flutter tests (161)
and analyze pass; the iOS simulator app builds; Android Kotlin compiles and its
unit tests pass. Voice, background sessions and picture in picture have not
been tried on physical phones yet.

Mobile version: 2.3.23, build 20331.

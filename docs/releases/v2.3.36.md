# Sanser 2.3.36

Exam rooms and smarter stream settings:

- **Exam mode (sidebar → Exam):** a supervisor creates a room and shares its
  6-character code. Students join from their own accounts; their computer is
  then held to the apps the supervisor chose, AI apps and AI websites are
  blocked, and Sanser cannot be quit or signed out of until the room ends.
  The supervisor sees every student's screen (refreshing every 2 seconds for
  the one being watched), the app in front and any violations (left the app,
  opened AI, went offline, tried to quit), and can pause, resume or remove a
  student, change the allowed apps, or end the room.
- **Suggest settings (Settings → Quality):** the server looks at both
  computers and the network and suggests resolution, FPS, bitrate, codec and
  network mode with short reasons. When the server has a language model
  (LM Studio, see docs/stream-advisor.md) it is used; otherwise built-in
  rules answer. Every answer stays within safe limits for both machines.

Server: new exam room and advisor endpoints (migration 0019 runs on start).

Checks: server tests (70 + 17), desktop Rust tests (154), lint, type check and
unit tests (393) pass. The exam lock is tested on macOS against a local
server; the Windows lock builds in CI only and has not been tried by hand.
macOS needs Screen Recording permission for screenshots and window titles.

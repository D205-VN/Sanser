# Sanser 2.3.28

- **Password reset in two steps:** after **Forgot password? / Quên mật
  khẩu?**, enter the 6-digit code from the email and press **Continue / Tiếp
  tục**. Sanser checks the code right away; a wrong code is reported on that
  step. Only a correct code leads to the next screen, where you enter the
  new password twice and press **Change password / Đổi mật khẩu**. **Enter a
  different code / Nhập mã khác** goes back to the code step.
- A too-weak new password keeps the checked code, so only the password needs
  to be typed again.
- **Server:** new endpoint `POST /api/v2/auth/password/check` checks a reset
  code without using it up. Each check counts toward the code's five
  attempts. See [email sign-in codes](../email-verification.md).

Checks: server unit tests (59), desktop tests (378) and mobile Flutter tests
(162) pass on macOS. The database-backed reset test runs in the CI
server-integration job.

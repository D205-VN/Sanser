# Sanser 2.3.9

A visual refresh of the desktop and mobile apps, and a quieter remote window.

- New shared palette (`design/tokens.json`): neutral ink surfaces with a single
  blue accent and a blue–violet gradient for primary actions. Desktop, mobile
  and native surfaces read the same tokens.
- Desktop: no text below 12 px, brighter secondary text, stronger control
  borders, a two-tone keyboard focus ring, legible disabled buttons, and 36–44 px
  targets. `prefers-contrast: more` and Windows forced colours are honoured.
- Desktop: removed repeated detail from everyday screens — the title-bar
  breadcrumb and account email, sidebar group labels, the brand subtitle, the
  heading count, six-character computer IDs and the "Updated" footer. They are
  hidden with CSS; the email remains in Settings → Account and the footer stays
  available to screen readers.
- Mobile: larger type (12 px minimum), token colours instead of translucent
  white for secondary text, pill status on computer cards, rounder cards and
  sheets, and clearer error notes. The About line no longer names the toolkit.
- Mac viewing Windows: in Ultra the latency overlay starts as one line (Ping,
  Jitter, Decode; red over budget). Control+Option+8 cycles compact → full
  table → hidden. Capture-paused and CPU-fallback warnings still use the full
  panel.

No transport, input or audio behaviour changes in this release.

The desktop frontend passed 303 tests and builds for production; the mobile
app passed 147 Flutter tests and static analysis. Desktop pages were reviewed
in a browser preview with stubbed account data. The mobile screens, the
one-line overlay in a live session, and pages that need an active connection
(sharing, group voice, file transfer) were not reviewed visually.

Mobile version: 2.3.9, build 20317. Android is signed locally with the existing
owner-held key. The iPhone IPA is unsigned and requires recipient signing; it
is not an App Store/TestFlight installation. Mac builds remain ad-hoc signed
when no signing certificate is configured.

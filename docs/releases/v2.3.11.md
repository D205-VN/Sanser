# Sanser 2.3.11

The first Mac build signed with a stable identity.

- Mac releases are now signed with the project's long-lived self-signed
  certificate instead of an ad-hoc signature. macOS identifies the app by that
  certificate rather than by each build's hash, so Screen & System Audio
  Recording and Accessibility grants are meant to carry over from one update to
  the next.
- **One more grant is required on this version.** Its identity differs from the
  earlier ad-hoc builds: after updating, remove the old Sanser entry in System
  Settings → Privacy & Security for Screen & System Audio Recording and
  Accessibility, add `/Applications/Sanser.app` again, then reopen Sanser.
  Later updates should not need this.
- The build is still not notarized: Gatekeeper warns on first open exactly as
  before.

No other changes from 2.3.10. Windows and mobile differ only in version number.

The release job fails if the built app's code requirement is not the
certificate. That a real grant survives a real update has not been verified
yet; it needs the update after this one.

Mobile version: 2.3.11, build 20319. Android is signed locally with the existing
owner-held key. The iPhone IPA is unsigned and requires recipient signing.

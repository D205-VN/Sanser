# Sanser v2.1.1

- The top-right **Update** button appears only when a newer version is available.
- The button stays hidden while checking, when up to date, or if the update service cannot be reached.
- Update checks run quietly at startup, every 15 minutes, and when the network reconnects.
- Choosing **Not now** keeps the update available from the button without reopening the dialog automatically.
- Update installation still waits until remote sessions finish.

## Downloads

- Windows x64: `Sanser-Windows-2.1.1-x64-setup.exe` or `Sanser-Windows-2.1.1-x64-portable.exe`.
- Mac Apple silicon: `Sanser-macOS-2.1.1-arm64.dmg`. Drag Sanser to Applications.
- Signed updater bundles and SHA256SUMS.txt are included.

The macOS app is ad-hoc signed, not Apple-notarized. If first launch is blocked, verify the download and use System Settings → Privacy & Security → Open Anyway. Windows installers do not yet have an Authenticode publisher certificate.
